2) Use only allowed signals listed below.
3) Keep antecedent and consequent purely boolean (no ##, no $past, no sequence operators).

8) Internal RTL names may appear below for understanding only. Never reference any name that is not in Allowed signals.

Allowed signals:
clk, rst_n, start, finish, state

Specification:
State machine transitions: IDLE->BUSY on start, BUSY->DONE on finish, DONE->IDLE in the next cycle.

Additional guidance:
- Waveform naming hints: state appears in waveforms as column 'state[1:0]'.
- Use numeric comparisons on state in the final assertion, not symbolic names: S_IDLE=2'd0, S_BUSY=2'd1, S_DONE=2'd2.

module dut_case04 (
    input  wire       clk,
    input  wire       rst_n,
    input  wire       start,
    input  wire       finish,
    output reg  [1:0] state
);
localparam S_IDLE = 2'd0;
localparam S_BUSY = 2'd1;
localparam S_DONE = 2'd2;

always @(posedge clk or negedge rst_n) begin
    if (!rst_n) begin
        state <= S_IDLE;
    end else begin
        case (state)
            S_IDLE: if (start)  state <= S_BUSY;
            S_BUSY: if (finish) state <= S_DONE;
            S_DONE:             state <= S_IDLE;
            default:            state <= S_IDLE;
        endcase
    end
end
endmodule

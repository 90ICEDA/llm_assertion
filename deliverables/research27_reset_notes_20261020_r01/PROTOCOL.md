# 复位后无请求输出：本轮执行约定

本轮只推进复位相关保护。使用已有 axis_fifo 原生运行器、独立端口事务队列、真实本地 Qwen、单条断言替换组装器和严格历史接受门控。没有远程调用额度，也不调用远程服务。

初始集合取 research26 r06 的最终冻结版本。其 a3 在输出接受时检查上一采样周期的队列计数，已有记录显示该条件漏过复位取消后的输出。其余四条断言必须原文保留。

新增 fresh-obligation 输入方式：根据义务标签定位唯一待替换槽位，不向模型重复旧断言文本。模型获得完整 RTL、测试平台、参考状态语义及本轮开发回放中的真实观察，自行生成完整表达式；不提供答案或修正模型输出。报告区分此种重新综合与旧表达式逐字修改。

开发集为原 15 个场景，加 research25 r01 和 research26 r02、r03、r04、r06 的全部 90 个公开测试场景，共 105 个。输入逐项保留原始值与来源哈希；全部属于开发数据，不能再计作本轮独立测试。

第一轮诊断按当前队列为空/非空选择实际未解决事件。前者检查没有待完成事务时的输出，后者检查复位取消的旧事务是否取代了新事务。归因 unknown 如实传递，不能作为已确认检出。

最多两次本地生成。每个候选都须原生编译并在全部开发数据上回放，只有当前缺口补上、历史检出及触发保留、合法事务没有新误报、关键结果没有 unknown 才接受。所有拒绝版本保留。

最终候选冻结后生成新的随机输入，按原运行器执行 Depth 4/8、Pipeline 2 的 18 个独立场景。不根据独立结果继续修改本轮候选。

验收范围：有限事务中的复位后输出保护。未建立完整 FIFO 五义务证明；也不声明背压期间 valid 保持或原始历史 RTL 缺陷已验证。人工输出边界故障与上游历史修复分开报告。

运行目录：`deliverables/research27_closed_loop_20261020_r01`。完整命令由运行器保存在 `execution.command.json`；源码、RTL、原生日志、模型请求和响应、修改轨迹及冻结哈希均保存于该目录。

## 第二轮开发调整

r01 两个模型输出均将输出保护依赖于输入握手；第一版已被原生回放拒绝。基于这些开发阶段结果，启动 `research27_closed_loop_20261020_r02`，最多两次本地调用，移除属性字符串的词法 pattern，保留 JSON 字段结构和不变的原生门控。同时补充缓冲 FIFO 输入空闲时仍可输出、当前输入数据不等于队首数据的语义说明。表达式仍完全由模型生成。

两个运行的独立数据在所有模型工作结束前均不读取。r02 沿用同一来源冻结集合与 105 个开发场景，不使用 r01 的独立结果。此调整同时改变提示和语法约束，不计作控制变量的机制消融，也不据此声称某个改动单独导致改善。两轮全部调用及拒绝版本均计入成本。

## 第三轮本地模型尝试

r02 两次生成均因缺少接口要求的显式时序蕴含运算符而拒绝，没有原生候选验证成功。r03 使用已安装的 `deepseek-coder:6.7b-instruct`，最多两次本地调用，沿用自由属性文本模式、105 个开发场景及严格门控。提示可包含实际接口错误信息；不包含手写正确表达式。所有先前独立测试继续封存至本轮模型工作完成。不同生成模型的结果单独记录，不作机制因果比较。

r03 和单独加载重试 r04 均在模型管理加载阶段中断，生成调用为 0，没有原生 core 回放。原始 running 状态另存，恢复记录确认实验进程已不存在。r04 服务日志显示 16K 上下文的 KV 缓存为 8192 MiB，WSL 物理内存约 8 GiB；该配置不能在加上权重后容纳于物理内存。退出的直接系统原因未恢复，不将推测的 OOM 当成已确认内核结论。

r05 请求新服务启用 flash attention 和 q4_0 KV 缓存，仅允许一次本地生成。环境覆盖值单独保存，服务不允许用这些参数悄悄复用已运行的旧实例。须依据实际服务日志确认支持及内存占用；参数请求本身不等于成功生效。不同缓存精度不是受控机制对比。

另已准备远程请求预览 `research27_remote_preview_20261020_r01/request.preview.json`。仅本地生成文件，未读取密钥或对外传输。此前远程调用额度已用完；新增两次调用的授权仍待用户明确答复。

## 用户授权后的远程执行

用户随后明确授权新增最多两次调用，记录在本目录 `authorization.json` 及 r06 运行目录。r06 使用同一初始集合与 105 个开发场景，真实调用 Highway/Qwen 72B 两次，额度已全部使用。第一条新候选检查所有 mvalid 周期，原生回放引入 288 条误报并被拒绝；第二条由模型自行改成输出握手接受时检查当前队列存在性及数据对应关系，进入完整历史回放。未人工替换表达式，未向模型提供独立测试。

r05 的量化缓存实际生效（2304 MiB，flash attention enabled），但输入 15056 tokens 加工程余量 384 和输出预留 1024 超过 16384，故在生成前拒绝。实际生成调用仍为 0；本地服务已核验归属并关闭。此资源改进不计为 SVA 修复成功。

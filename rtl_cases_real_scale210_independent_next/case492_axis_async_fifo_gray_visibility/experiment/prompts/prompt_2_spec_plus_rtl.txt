Generate SystemVerilog assertions using @(posedge clk_i) disable iff (!rst_ni).

Use only allowed signals. Output assertion lines only.

Allowed signals:

clk_i, rst_ni, write_toggle_i, sample_enable_i, q_o, state_o

A write-toggle crossing into the read domain becomes visible only after all three synchronizer stages; the second-stage value is not externally visible.

RTL:

`timescale 1ns/1ps
module axis_async_fifo(
  input wire clk_i,
  input wire rst_ni,
  input wire write_toggle_i,
  input wire sample_enable_i,

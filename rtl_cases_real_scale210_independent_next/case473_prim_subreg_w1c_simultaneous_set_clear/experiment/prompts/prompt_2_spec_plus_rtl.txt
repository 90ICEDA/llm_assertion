Generate SystemVerilog assertions using @(posedge clk_i) disable iff (!rst_ni).

Use only allowed signals. Output assertion lines only.

Allowed signals:

clk_i, rst_ni, we, wd, de, d, q, ds, qs

Specification:

For a W1C subregister, a hardware write supplies the candidate set value and a simultaneous software write clears every bit selected by `wd`. Thus the next value is `d & ~wd` on a collision; software clear wins only on overlapping bits.

RTL:

`timescale 1ns/1ps
// OpenTitan prim_subreg W1C arbitration extraction.
module prim_subreg #(
  parameter integer DW=8, parameter [DW-1:0] RESVAL=0
)(
  input wire clk_i,rst_ni,we,de,
  input wire [DW-1:0] wd,d,
  output wire qe,
  output reg [DW-1:0] q,
  output wire [DW-1:0] ds,qs
);
  wire wr_en=we|de;
  // For W1C, HW may set while SW clears; an overlapping SW clear wins per bit.
  wire [DW-1:0] wr_data=(de?d:q)&(we?~wd:{DW{1'b1}});
  always @(posedge clk_i or negedge rst_ni)
    if(!rst_ni) q<=RESVAL; else if(wr_en) q<=wr_data;
  assign ds=wr_en?wr_data:q;
  assign qs=q;
  assign qe=we;
endmodule
